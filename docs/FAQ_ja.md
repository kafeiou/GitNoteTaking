# よくある質問 (FAQ) - GitHub 認証と同期について

## Q1: 同期時に「GitHub 認証の期限切れまたは失敗」と表示されるのはなぜですか？

### 原因の説明
InMethod GitNoteTaking は GitHub OAuth Web ログイン認証に対応しています。GitHub の公式セキュリティポリシーにより、GitHub OAuth App で「**Expire user authorization tokens**（ユーザー認証トークンを期限切れにする）」が有効になっている場合、発行される Access Token の有効期限は **8 時間**となります。

8 時間を超えてトークンが更新されない場合、GitHub サーバーは Git 操作を拒否し、`HTTP 401 Unauthorized`（`not authorized`）を返すため、プッシュ（Push）やプル（Pull）ができなくなります。

---

## Q2: 認証の期限が切れた場合、書いたノートは消えてしまいますか？ 同期を再開するにはどうすればよいですか？

**ノートが消えることは一切ありません！**

ローカルで変更したノートは、端末内のローカル Git リポジトリに安全に保存されています。同期時に認証期限切れが発生した場合、アプリは自動保護および回復メカニズムを開始します。

### 同期再開の手順：
1. **再ログインをタップ**：「GitHub 認証期限切れ」ダイアログが表示されたら、「**再ログインして同期**」をタップします。
2. **Web 認証の実行**：ブラウザで GitHub 公式認証ページが開きます。「**Authorize**」をタップして承認します。
3. **自動再プッシュ**：認証成功後、アプリに戻ると**保留中だった未プッシュのノートが自動的にプッシュ**されます。再度手動で編集や同期操作を行う必要はありません。

> **ヒント**：メイン画面で対象のリポジトリを長押し ->「**編集**」->「**GitHub Web 経由で再ログイン認証**」をタップすることで、いつでも手動で認証を更新できます。

## Q3: ［開発者／OAuth App 管理者向け］GitHub 認証トークンを無期限にするには？

ご自身で GitHub OAuth App を管理されている場合、8 時間の有効期限制限を無効化して無期限トークンを発行できます：

1. [GitHub](https://github.com/) にログインします。
2. 右上のプロフィールアイコンをクリック -> **Settings**（設定）へ進みます。
3. 左サイドバー最下部の **Developer settings**（開発者設定）をクリックします。
4. **OAuth Apps** を選択し、お使いの GitNoteTaking アプリケーションをクリックします。
5. **Optional features** セクションにある **Expire user authorization tokens** を探します。
6. **チェックを外します**（Uncheck / オプトアウト）。
7. **Save changes** をクリックして保存します。

> チェックを外すと、今後この OAuth App 経由でログインするすべてのユーザーに対して、無期限の Access Token が発行されるようになります（ユーザー自身が GitHub で連携解除しない限り有効）。

## Q4: GitHub パーソナルアクセストークン（PAT）を使用できますか？

**はい、利用可能です！**

Web OAuth を使用しない場合は、GitHub の Personal Access Token を設定することもできます：

1. GitHub の **Settings** -> **Developer settings** -> **Personal access tokens** -> **Tokens (classic)** へ進みます。
2. **Generate new token (classic)** をクリックします。
3. Note に `GitNoteTaking` と入力し、Expiration で **No expiration**（無期限）を選択、**repo** スコープにチェックを入れます。
4. トークンを生成してコピーします（例：`ghp_xxxx...`）。
5. GitNoteTaking アプリで設定します：
   - 新規リポジトリの場合：「リモートリポジトリのクローン」画面で、アカウントに GitHub ユーザー名、パスワード欄に生成したトークンを貼り付けます。
   - 既存リポジトリの場合：リポジトリ一覧で長押しして「編集」を選択し、パスワード欄に新しいトークンを貼り付けて「OK」をタップします。
