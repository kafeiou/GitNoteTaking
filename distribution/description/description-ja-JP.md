# ソフトウェアエンジニア専用・ギークのための Git ノート
# 性能の低いスマートフォンへのインストールはお控えください

「編集するたびに、その理由をコミットメッセージに残す。それがエンジニアの流儀。」

【Git 文字ノート)開発者向けGitノート。メモやコードをGitで版控管理し、GitHub等のサーバーと安全に同期できます。

## ⚡ 主な特徴
1. **本格的な Git バージョン管理**：保存時にコミットメッセージを記録。変更履歴を完全に追跡し、いつでも過去の状態を確認・復元可能。
2. **GitHub OAuth 2.0 ワンタップ認証**：面倒な Token のコピーは不要。ブラウザ認証後、note* で始まるノートリポジトリを自動で一覧表示・連携（PAT 手動入力もサポート）。
3. **柔軟な Git サーバー対応**：GitLab、Gitea、自作のプライベート Git サーバーに対応。アカウント不要の完全ローカルオフラインノートも作成可能。
4. **オフラインファースト＆双方向同期**：圏外でも自由に編集でき、オンライン時にワンタップで Push / Pull 同期。
5. **正確なコミット更新日時の同期**：GraphQL を活用し、リモートの最新コミット日時をローカルファイルに正確に反映。
6. **Git 履歴パージ機能 (Purge to Depth 1)**：設定画面からローカルの長大な履歴を整理し、最新状態（depth=1）にして端末ストレージを解放。
7. **全文検索＆ファイル添付**：高速なテキスト全文検索に対応。Android 標準ファイルピッカーによる安心の権限不要ファイル添付。
8. **ワンタップ ZIP 完全バックアップ**：いつでもすべてのノートを ZIP 圧縮してダウンロードフォルダへ出力可能。
9. **100% オープンソース＆プライバシー重視**：サードパーティサーバーを経由せず、直接 Git サーバーと安全に通信。

## 🚀 3 ステップ簡単スタート
1. GitHub で「note」から始まるプライベート (Private) リポジトリを作成（例: note-work, note-daily）。
2. アプリを開き、右上の「作成 ➔ GitHub ノートを作成」から【🐙 GitHub 認証】をタップ。
3. リストからリポジトリを選択するだけで自動 Clone が完了し、すぐに利用できます！

*(「リモートノートを取得」から自作 Git サーバーの URL / 認証情報を入力して接続することも可能です)*
