“每次编辑的时候，写下编辑的原因，才是工程师该有的浪漫。”

【GIT 文字笔记 Git Note Taking】是专为软件开发者与极客打造的文字笔记工具。将您的日常笔记、代码片段与备忘录，通过标准 Git 版本控制机制进行管理，并安全同步至全球最大的开源平台 GitHub 或任何自建 Git 服务器！

## ⚡ 核心特色
1. **完整 Git 版本控制**：每次保存均可记录 Commit 提交信息，完整追踪修改原因与历史演进，随时查看与回滚。
2. **GitHub OAuth 2.0 一键授权**：无需手动复制粘贴繁琐的 Token，浏览器授权后秒速自动列出并绑定 note* 笔记仓库（同时保留 PAT 手动模式）。
3. **支持自建与各类 Git 平台**：完美兼容 GitLab、Gitea、自建私有 Git 服务器，亦可建立纯本地离线笔记（无需任何账号）。
4. **离线优先与双向同步**：无网络时随时随地编辑，联网时一键 Push / Pull 双向同步。
5. **智能 Commit 真实日期同步**：借助 GraphQL 技术，下载笔记时精准校正远端文件的真实最后修改时间。
6. **历史记录瘦身 (Purge to Depth 1)**：在“设置”中一键清除本机冗长历史，释放手机空间。
7. **全文搜索与文件附件**：即时检索笔记内容，并通过原生系统选择器零权限安全夹带图片与附件。
8. **一键 ZIP 离线完整备份**：随时将笔记打包备份至手机下载目录。
9. **100% 隐私透明与开源**：App 直连您的 Git 服务器，绝无任何第三方中转或收集数据。

## 🚀 3 步快速上手
1. 在 GitHub 上创建一个名称以“note”开头的私有 (Private) 仓库（例如 note-work、note-daily）。
2. 打开 App，在右上角点击“创建 ➔ 创建 GitHub 笔记”，点击【🐙 一键登录 GitHub 授权】。
3. 在弹出的列表中点击目标仓库，系统自动完成 Clone，立即开始享受 Git 版控笔记！

*(亦可在“下载远端笔记”中输入任意自建 Git 服务器之 URL / 账号密码进行连接)*
