# 軟件工程師專用、麻瓜勿擾
# 手機不夠好請不要安裝

「每次編輯的時候，寫下編輯的原因，才是工程師該有的浪漫。」

【GIT 文字筆記 Git Note Taking】是專為軟件開發者與技術極客打造的文字筆記工具。將您的日常筆記、程式碼片段與備忘錄，透過標準 Git 版本控制機制進行管理，並安全同步至世界上最龐大的開源平台 GitHub 或任何自建 Git 伺服器！

## ⚡ 核心特色
1. **完整 Git 版控核心**：每次儲存皆可記錄 Commit 訊息，完整追蹤修改原因與歷史演變，隨時檢視與還原。
2. **GitHub OAuth 2.0 一鍵授權**：無需手動複製貼上繁瑣的 Token，瀏覽器授權後即可秒速自動列出並綁定 note* 筆記儲存庫（亦完整保留 PAT 手動模式）。
3. **支援自建與各類 Git 服務**：完美相容 GitLab、Gitea、自建私有 Git 伺服器，亦可建立純本機離線筆記（無需任何帳號）。
4. **離線優先與雙向同步**：無網絡時隨心編輯，連網時一鍵 Push / Pull 雙向同步。
5. **智慧 Commit 真實日期同步**：透過 GraphQL 技術，下載筆記時精準校正遠端檔案的真實最後修改時間。
6. **歷史紀錄瘦身 (Purge to Depth 1)**：在「設定」中一鍵清除本機冗長歷程，釋放手機空間。
7. **全文搜尋與檔案夾帶**：即時檢索筆記內容，並透過原生系統選擇器零權限安全夾帶圖片與附件。
8. **一鍵 ZIP 離線完整備份**：隨時將筆記打包備份至手機下載目錄。
9. **100% 隱私透明與開源**：App 直連您的 Git 伺服器，絕無任何第三方伺服器中轉或收集資料。

## 🚀 3 步快速上手
1. 在 GitHub 上建立一個名稱以「note」開頭的私有 (Private) 儲存庫（例如 note-work、note-daily）。
2. 開啟 App，在右上角點選「建立 ➔ 建立 GitHub 筆記」，點擊【🐙 一鍵登入 GitHub 授權】。
3. 在跳出的清單中點選目標儲存庫，系統自動完成 Clone，立刻開始享受 Git 版控筆記！

*(亦可在「下載遠端筆記」中輸入任意自建 Git 伺服器之 URL / 帳密進行連線)*
